# Phase 8 · 01 — Simple menu

Implemented on `phase8/01-simple-menu`. No dependencies installed, no push or deployment.

## Result

- Title has three large choices (Fly a Mission, Survival, Co-op), two small links (Hangar, Settings), and one optional Hangar notification dot. Removed automatic bulletin/training overlays and secondary title injectors.
- Fly opens the next unlocked campaign briefing directly. Campaign order, including story escort chapters, is preserved; the full map remains in Hangar.
- Survival defaults to B-17. A collapsed More modes disclosure contains the other modes, including P-51 and Daily Run. Leaderboards moved to Records; local scores remain available there. Co-op still defaults to B-17 crew.
- Four Hangar tabs retain the existing features. Child screens receive explicit return callbacks; Escape returns one level and preserves the active tab. Skill branches, Settings and Custom Battle use grouped controls. Armory and Customize reuse the existing loadout screen with relevant sections shown.
- New profiles enter Gunnery School automatically, then return to the clean title. The launch flag is saved before starting, so quitting/reloading cannot repeat the automatic launch. Existing progress and old dismissal flags are respected. Training remains in Hangar → More.
- New strings have Arabic translations. Logical alignment, keyboard tab navigation, touch targets and scrolling support desktop and phone layouts.
