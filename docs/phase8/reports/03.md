# Phase 8 goal 03 — gunner survival

Implemented on `phase8/03-gunner-survival`.

- Damage-triggered oxygen hose failures, O reconnect, automatic crew rescue, gradual hypoxia blur/tunnel vision and slower aim.
- Heated-suit electrical faults and automatic repair; weather-sensitive cooling, existing glass/window frost, receiver/cover frost and a brief first-burst thaw.
- Per-station jams, shared two-minute minimum interval, hold R or double-tap clearing, charging-handle motion and metallic sounds.
- Finite station belts/boxes, visibly shortening belts, actual ammo count, waist ammo-can reload animation, automatic crew delivery and fixed turret-box servicing.
- Wound sway and tunnel severity follow existing player wounds and field dressing. Recruit disables random failures/freezing/ammo consumption; Veteran and Ace use separate tuning.
- Small status icons and one contextual instruction in the existing HUD gap; no new panel. English/Arabic coverage and four Chatterbox radio recordings.

## Files and hooks

- `src/game/GunnerSurvival.ts`: pure state/rules, difficulty and ammo tables; `GunnerSurvivalHud.ts`: cached labels, O₂ blinker and tunnel overlay.
- `GunnerController.ts:55, 399, 415, 420`: ownership, station jam bridge, refill/reset, input/timing/fire/visual integration. Switching stations now selects the new state before updating the gun that frame. Perk changes no longer refill belts.
- `Viewmodels.ts:187`: charging handle, receiver/cover frost and ammo can. Frost shares the shader already warmed through `World.prewarm → warmLivingInterior`; no new material program is introduced.
- `WorldEvents.ts:109`: heavy-hit failure hook; `MissionFlow.ts:96`: difficulty initialization; `RandomEvents.ts:326`: legacy oxygen/jam events remain pilot-only to avoid duplicate gunner interruptions.
- `Game.ts:545`, `render/PostFX.ts:169`: hypoxia uniform/reset in the existing post pass; `GameHud.ts:111,324`, `ui/UI.ts:334`: actual ammo and compact status drawing.
- `i18n/ar/gunnerSurvival.ts`, `i18n/phrases.ts`: Arabic; `tools/voice/lines.json`, `src/audio/voiceLines.ts`, voice manifest and four `public/audio/voice/gs_*.m4a` files: recorded calls.
- `tests/gunnerSurvival.test.ts`: 12 rule tests. `tools/gunner_survival_browser_check.mjs`: reproducible browser verification using an already installed Playwright.
- Numbers and balancing rationale: [BALANCE.md](../../BALANCE.md#phase-8-goal-03--gunner-survival).

## Scope notes

Failure states were deliberately forced in the browser for repeatable effect/recovery checks; normal spawn scheduling was disabled for those captures. This is not a campaign win-rate regression or a listening review of the generated voices. The existing radio-room crew member is not a playable gun station, so ammo-can handling covers the two playable waist positions. Crew deliveries repeat indefinitely for survival fairness. No dependencies installed; no push or deployment.
