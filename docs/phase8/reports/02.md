# Phase 8 · 02 — Clean HUD and simple settings

Implemented on `phase8/02-clean-hud`.

- Saved Minimal / Standard (default for old saves) / Full policy, shared by B-17 and P-51. Minimal keeps gun information, damage silhouette, incoming-fire arcs and subtitles. Essential touch input remains usable. Standard adds score/round, one objective/action line, up to three fast-fading feed entries, ready abilities and smaller 0.85-second score popups.
- Achievements, upgrades and service notifications share one queue: 2.5 seconds visible per item, deferred in Minimal and during Standard incoming fire. An interrupted toast retains its remaining time. Context hints stay single-line and once-per-profile; the controls reminder stops after the first two missions.
- Basic settings contain the requested nine controls/groups. Advanced retains existing controls, including Ultra, accessibility, cloud save and manuals. Auto runs the existing graphics detector; difficulty uses the unchanged balance factors. Voice has its own gain control. Hangar → Settings returns to the same hangar; Space in Settings cannot launch the next round.
- Arabic phrases and responsive RTL layouts added. No dependencies, materials or shaders added.
