## Visibility and audit contract

World-attached markers require a live, non-falling, non-removed target in the current world; a visible, nonzero-scale model attached to the scene; night spotting; and the shared atmosphere rule. Range retains the existing weather spotting fade. Fog/haze follows exponential transmission, hiding below 35%. A populated cloud slab fades labels over its first 80 m of sightline, then hides them. This deliberately conservative CPU rule can hide labels in clear holes within the GPU cloud noise; it works on Low and with weather effects disabled without GPU readbacks.

`src/ui/MarkerAudit.ts:13` exports pure `auditMarkers(samples, tolerancePx = 2)`. Draw sites record target IDs, marker kind, mode and anchors into a reusable dev pool. Snapshotting independently reprojects the live rendered transform, checks target existence/liveness/visibility and requires world-marker anchors within **2 CSS pixels**. Health bars/name tags use their aircraft attachment anchor; boss/sea parts use their local part anchor. Directional arrows, radar contacts and recent-hit arcs report front/visibility but are not assertions of an aircraft at their HUD coordinates. Only labelled forecasts and shooterless damage events may lack a live aircraft.

Hooks: `src/core/Engine.ts:325` resets capture per frame; `src/main.ts:68` exposes dev-only `sws.markerAudit()` and `sws.markerAuditRun()`. `src/dev/MarkerScenarios.ts:15` drives real mission controllers with `sws.step(60, 1/60, false)`, auditing every simulation frame and again after each batch's actual WebGL render. The suite injects front/rear fighters, pans and alternates zoom, exercises shake, forces real floating-origin rebases, kills/despawns injected contacts, and tracks real raid/ace/ship targets. Invulnerability and periodic pilot positioning keep the test in combat; this is a marker regression, not a gameplay-balance run.

## Remaining hypotheses / limits

Reviewed Aircraft, World, FighterDeath and Wrecks: simulation positions are the mesh roots themselves; deaths clear `alive`, removal detaches roots, and no live-aircraft pooling/LOD ghost was found. Models have visible fallback geometry and mission startup waits for assets. Co-op interpolation writes directly to each local proxy root; no host screen coordinates are transmitted. Photo, theatre and bookend cameras already hide/clear combat HUDs. No alternate-camera classification bug was found; the same projection guard now protects partner tags too.

No live two-peer network session was run. The audit verifies the documented CPU fog/cloud policy and rendered transforms, not per-pixel GPU occlusion or photometric aircraft contrast. No pending implementation work within the task's requested scenarios. Dev server stopped after verification; no push or deploy.
