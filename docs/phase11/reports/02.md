## Changes / hooks

- `src/render/AircraftFinish.ts`: baked-ORM-aware satin paint, UV-oriented brushed-metal normal response, and geometric-horizon specular occlusion. True GGX anisotropy is not claimed. Existing baked AO and contact GTAO remain.
- `src/render/GlassReflection.ts`: ten bounded steps through existing HDR cloud/opaque colour and **the safe, half-resolution linear SoftDepth copy**. Rejects foreground/self intersections and fades screen edges; missing/offscreen geometry falls back to sky IBL. Glass uses dielectric Fresnel alpha and specular lighting rather than adding opaque diffuse shading.
- `src/render/MaterialAudit.ts:20`: preserves existing hooks/cache keys, installs clone-safe finish uniforms and compiles reflection samplers only for glass. `src/world/Models.ts:88`: clear dielectric setup before prewarm; removes the redundant physical-transmission pass.
- `src/core/Engine.ts:487,495`: request the existing depth copy and bind reflection inputs immediately before transparency. High/Ultra/Cinematic trace; Low/Medium use IBL. `:449,539` disable tracing during opaque/studio work. Existing `World.prewarm` → `Engine.warmRenderer` warms the variants; no new World/Game hook.
- `src/game/GlassFx.ts:354`: shared reflection lookup on turret/canopy overlays, with the existing sight-clearance mask and Low exclusion.
- `src/render/SunCascades.ts:28,81`: formation map shifts 85 m toward the view and fits a 345.6 m square, improving texel spacing from **25.4 cm to 16.9 cm** at 2048 without increasing map size/cadence. Fitted edges blend to the far map. Close contact shadows retain their original per-frame map.
- `src/render/Sky.ts:111,150`: weather-refreshed PMREM now includes broad cloud variation rather than a uniform floor; direct sun disk remains excluded. `FilmLUT.ts` refines warm/cold/overcast/dusk colour balance using [Poly Haven CC0 HDR sky references](../shots/02/CREDITS.md). No reference image ships in the game.
- Added focused unit tests, GPU runtime checks, comparison/performance tools, architecture notes and compact JPEG evidence. No player-visible text or radio changes.

## Limits

Screen-space reflections cannot recover offscreen/hidden aircraft and intentionally use IBL there. The environment cloud pattern is an inexpensive broad approximation, not a second volumetric-cloud render. Brushed metal uses a normal response approximation rather than a physical anisotropic BRDF. No extra reflection render target or full-scene pass is added; High+ requests the existing SoftDepth pass even when no soft particles are visible. Frozen rendering and compile stability are covered; long combat, other GPUs and all five preset performance budgets were not requalified. Existing Low interior obstruction and top-gun texture artefacts remain outside this task.
