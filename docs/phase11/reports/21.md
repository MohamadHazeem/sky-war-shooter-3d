# Phase 11 · 21 — Station tutorials: report

Branch `phase11/21-station-tutorials` (cloud lane, Claude). Spec: `docs/phase11/21-station-tutorials.md`.

## What changed
There are now four short interactive lessons, one for each gun position. Each one starts and ends with the same measured drill:

| Lesson | Station | Teaches | Steps |
|---|---|---|---|
| Leading targets | Left waist | Lead pip, then leading by eye | warm-up drill · hold the sight on the ◇ for 1 s (pip forced on) · kill with the pip · kill by eye · final drill |
| Convergence | Top turret | Twin .50s cross at `TWIN_CONVERGENCE` (300 m) | drill · kill at 300 m · a drone closes in from 1150 m: wait until it's inside 400 m (the card shows the range and counts rounds wasted beyond 600 m) · drill |
| Ammo and jams | Ball turret | Short bursts, turret resupply, clearing jams | drill · 3 short bursts (≤ 0.9 s; long ones are flagged) · forced jam, cleared with the real R handling (hold or double-tap) · kill a drone that jams the gun half way · drill |
| Oxygen | Tail gun | Loose mask hose, hypoxia, the O key | drill · hose comes loose, the picture greys within seconds, press O · kill a drone while the hose comes loose mid-fight (the step needs the kill *and* the hose reconnected) · drill |

- **Progressive unlock.** Waist is always open. Each next lesson opens once the one before it is completed or skipped.
- **Skippable.** Any step can be skipped in flight with Backspace, or with the card's "Skip step" button on touch. A whole lesson can be skipped from the Training screen, which unlocks the next one. Every step also has a timeout (≤ 60 s), so a lesson can never get stuck.
- **Measured.** Saved locally in `sws3d.lessons.v1`, per lesson: attempts, completions, best time, and the hits/rounds accuracy of the warm-up drill vs the final drill (same drone, same path). It also records the steps skipped and timed out. A skipped drill is never measured. The Training screen shows "Accuracy a → b" for each lesson, plus totals (complete n / 4, average change in points). The finale card shows the same figures.
- **Training screen.** Hangar → Training now opens this screen instead of starting the Gunnery School directly. It lists the Gunnery School and the 4 lessons with their state (New / Locked / Skipped / Done) and Start / Fly again / Skip buttons. It uses the Phase 8 sheet (`menu-sheet` + `menu-choice` styles), Back / Esc / Backspace, and has 44 px touch targets. When a lesson ends you come back to this screen, with the next lesson highlighted.
- **Same safe sky as the Gunnery School.** Lessons are `tutorial: true` missions, so every system that skips the tutorial also skips them: no damage, no flak, gunless drones.

## Review fixes
- **Card header on one line.** The station sits on the start side (ellipsis if needed) and "STEP n / m" on the end side, in khaki and never wrapping (`LessonRunner.render`, `onboarding.css`). The script asserts a one-line header on every card, in English, Arabic and on the phone.
- **Phone landscape (height ≤ 500 px).** A compact lesson card sits under the score line. While the card shows, the radio subtitles move to the free side (`body:has(#tutCard.lesson.show) #subs`, mirrored in RTL), so they no longer run under the card.
- **Training sheet at 720p.** All 5 rows fit at 720p (since c5572ea, now shown in the shot). Shorter screens scroll the sheet, with the ▼ hint.
- **Voice lines.** The 16 lesson radio lines are now in `tools/voice/lines.json`, in a new group "Phase 11 station lessons", **before** the briefings group. The final-drill line is shared by the four lessons. `python3 tools/voice/generate.py --check` passes. The clips themselves still need `generate.py` on the Mac; this cloud machine has no `say` / `afconvert`. Until then the lines play as subtitles.

## Not done / notes
- **Voice clips not rendered yet.** The lines are in `tools/voice/lines.json`, but rendering them needs macOS (`python3 tools/voice/generate.py`). Until it runs, they stay subtitle-only.
- **No Blender / GPU work needed.** The capture-rig quality gate (`tools/visual_rig.mjs`) wasn't run: this goal adds no graphics, and software rendering here takes minutes per frame.
- **Measurement is local only.** Results are not sent through `net/Analytics.ts`, because that would need a new event shape and a Firestore rules merge. Read them with `JSON.parse(localStorage['sws3d.lessons.v1'])` or `lessonMetrics(loadLessonProgress())`.
- **Pre-existing, not changed here:** the default Standard HUD (`HudDetail.ts`, `markers: false`) hides target markers and the lead pip. So the Gunnery School's "red brackets" / "◇ lead indicator" instructions point at things a default player doesn't see. The lessons force the pip on for the steps that need it.
- A lesson finished with every step skipped still counts as completed (with `stepsSkipped` recorded and no accuracy), so it still unlocks the next one.
