# Phase 11 · 00 — Conflict-free shared registries: report

Branch `phase11/00-conflict-free`. Process change only: no gameplay, assets, Arabic text or voice clips changed.

## What changed
1. **Arabic tables auto-discovered** (`src/i18n/phrases.ts`). The explicit `TABLES` list and its order are
   untouched. `withDiscovered(TABLES, import.meta.glob('./ar/*.ts', { eager: true }))` finds every
   `src/i18n/ar/*.ts` module whose default export is a `PhraseTable` and is not in `TABLES`, sorts them
   by file path and puts them FIRST (lowest precedence, like today's convention of prepending new tables).
   Helper modules without a table (`fmt.ts`) are skipped. New exports: `withDiscovered`, `ALL_TABLES`;
   `PHRASES` / `PATTERNS` are now built from `ALL_TABLES`. Today `ALL_TABLES` equals `TABLES`, so the
   phrase map is unchanged. A new goal only adds `src/i18n/ar/<goal>.ts`.
2. **Voice line groups in `tools/voice/lines.d/*.json`** (`tools/voice/generate.py` → `load()`). Each file is a
   JSON array starting with a `{"group": "..."}` header; files load in sorted filename order and are
   inserted just before the `briefings (tools/voice/briefings.mjs)` group (malformed file → clear exit).
   No `lines.d` directory is committed (none is needed; the loader handles its absence).
3. **Docs**: `AGENTS.md` Arabic/voice rules now say "new table file, don't edit phrases.ts" and "new radio
   lines go in a new `tools/voice/lines.d/<goal>.json`"; `tools/voice/README.md` documents `lines.d`.
