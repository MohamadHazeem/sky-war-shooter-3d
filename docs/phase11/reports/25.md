# Phase 11 goal 25 — The ground war below

Branch: `phase11/25-ground-war`. Capture server: **5325** (the task file did not specify a port).

## Changes

- Wind-driven soot columns have rolling, irregular edges, narrower cores and less orange haze. Preceding-wave columns now extend to the ground before bomb release, with burning works beneath them. The existing walking bomb impacts, scars, secondaries and flak clocks remain connected to the real formation release.
- Moving freight traffic follows a through line beside the river/rail yard, with separate wagons and locomotive exhaust. The train wraps beyond the visible line.
- Airport target layouts (Regensburg/Leipzig) gain taxiways, dispersals and runway markings. Three staggered, pooled aircraft silhouettes accelerate, rotate and climb with altitude-correct parallax and separate ground shadows.
- Four-gun earthworks mark the existing flashing flak batteries between salvos; mapped water suppresses misplaced flashes.
- Activity uses the existing sky/ground shader and pooled uniforms, without additional draw calls, render targets, textures or runtime shader variants. Plume growth/density is calculated once per frame instead of per sky pixel. The existing `World.prewarm` path warms target smoke. Low retains the activity and uses half the smoke puffs; invisible puffs are clipped before rasterization.

## Files and hooks

- `src/world/GroundWarMath.ts`: deterministic allocation-free train and sortie schedules.
- `src/render/GroundWar.ts`: pooled uniform updates; freight, airfield and projected aircraft shading.
- `src/render/TargetGround.ts`: activity shader inclusion, flak earthworks and fire/smoke integration.
- `src/render/TargetSmoke.ts`: turbulent cloud-height smoke and preset culling.
- `src/world/TargetArea.ts`: `syncGroundWar` at line 295, reset at line 171, plume-profile sync at line 337 and city-axis source placement at line 331; no Game/World/UI changes.
- `tests/groundWar.test.ts`: acceleration/liftoff, staggered looping, negative clocks, train speed/wrap, airport gating stable pooled identities and bounded smoke growth.
- `tools/ground_war_capture.mjs`: live/main comparison using the Phase 10 fixture conventions (seed, 18 bombers, fixed weather, manually driven frames, identical cameras), plus High/Low runtime checks.

No new player text, radio lines, dependencies or generated assets.

## Scope

The trains and distant fighters are scenery, with screen-size filtering for readability at 25,000 ft. They do not create combat targets, score, collisions or new AI. Aircraft use projected silhouettes in the existing terrain shader; this is an altitude view, not a new low-level airfield mode. Existing real-map terrain and cloud occlusion remain in use.
