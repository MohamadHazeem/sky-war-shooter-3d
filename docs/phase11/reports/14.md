# Phase 11 · 14 — Gamepad and accessibility (report)

Branch `phase11/14-gamepad-accessibility` · lane: Claude cloud session (no Blender / voice / GPU on this machine).

A lot of this goal already existed before Phase 11: full gamepad play (gunner, P-51, photo mode, replay theatre,
D-pad / A / B menu navigation), keyboard remapping, a colour-blind on/off switch, subtitle size / background and one
"reduce shake and flashes" switch. This goal fills the gaps.

## What changed
1. **Gamepad remapping** (`src/core/PadMap.ts`, new). 14 in-flight actions (fire, zoom, reload / prompt, bombsight,
   previous / next gun, map, ping, two wingman orders, three abilities, free look) can be moved to any button. It works
   like `KeyMap`: physical buttons go through a permutation into the logical ones `Gamepad.ts` already reads, so no
   controller code changed. Binding a used button swaps the two actions. Start and View are fixed, so a player can't lock
   themselves out. Menus, photo mode and the theatre keep the standard layout. Saved under `sws3d.pad.v1`; a corrupt
   save (not a permutation) falls back to the defaults.
   - Capture runs on the gamepad itself (Settings → Advanced → Gamepad buttons): press A on a row, then the new button.
     Start, View or Esc cancel. The button still held from the A press is ignored.
   - The controls card (`ControlsCard.ts`) and the bombsight offer (`Bombardier.ts`) show the remapped buttons.
2. **Full gunner pad coverage**: D-pad right now pings the target for the crew (`KeyU`). That was the last gunner action
   with no button. All stations, bombsight, prompts (oxygen / fire / jam through X) and abilities are covered.
3. **Menus, Hangar, Tour**: after A presses a control and the screen redraws itself (the Hangar re-renders on every
   purchase), focus goes back to the same control (`refocus` in `Gamepad.ts`), so it no longer jumps to the top. When
   the Hangar is opened from a menu (its button reads "Back"), that button is now the pad's B target (`data-back`). The
   campaign / Tour map markers, op cards and Hangar folds were already focusable.
4. **Gamepad comfort**: aim speed slider (`padSens`) and left-handed sticks (`padSwap`: the gunner aims with the left
   stick, the P-51 flies on the right).
5. **Aim-assist presets** (`src/core/AimAssist.ts`, new): Off / Low / High / **Strong (accessibility)** (1.5×: wider
   lock cone, firmer pull). With "Stronger aim assist on a gamepad" (on by default), playing on a pad raises the preset one
   step. Off always stays off. `DeviceControls` follows which device is in use (pad input vs real mouse / keyboard) and
   re-applies `Game.applyAssist()` when that changes.
6. **Colour-blind safe markers and HUD** (`Accessibility.ts`): the switch is now a mode: Off / Red-green (the existing
   orange vs blue) / Blue-yellow safe (pink foes vs teal friends) / High contrast (yellow vs white, heavier HUD text and
   plates). Target markers and the radar read the palette. HUD CSS uses `--cb-enemy` / `--cb-friend`. Threat seats and
   wounded crew also get dashed borders, so colour is never the only cue. Old saves migrate (`colorBlind: true` → red-green).
7. **Subtitles**: new Extra large size (1.8×). Background opacity as before.
8. **Reduce motion / reduce flashes** are now two switches. `access.shake` / `hitStop` / slow motion follow motion.
   `access.flash` (muzzle light, lightning, glints, damage flash) and the red vignette / fire frame (`body.noflash`) follow
   flashes. Old saves copy the single switch into both.
9. **One-handed mouse mode** (`src/core/OneHanded.ts`, new): the gunner can play with a mouse alone. Wheel = previous / next
   gun position (debounced), middle click = reload (held half a second = bombsight; held while an emergency prompt shows =
   that prompt's key), back / forward side buttons = Mustangs / Overdrive. Browser back / forward and autoscroll are
   suppressed only while the mode is on and a mission is being flown.
10. **Arabic**: new table `src/i18n/ar/accessibility.ts` (prepended in `phrases.ts`) for every new string.

## Hook lines in shared files
- `Game.ts`: `applyAssist()` made public and uses `assistStrength(settings.aimAssist, padAssist)`, plus a `padAssist` field.
- `UI.ts`: `aimAssist: AssistLevel` type, a `strong` option in the aim-assist select, `data-back` on the Hangar's Back button.
- `DeviceControls.ts`: creates `OneHandedMouse`, shares `cycleSeat`, tracks pad use → `game.applyAssist()`.
- `phrases.ts`: registers the new table.
