# Phase 11 · 34 — Spectator and streamer mode: report

Branch `phase11/34-spectator-streaming` · lane: Claude (second account) · dev server for checks: port 5334.

## What changed

**Spectators for B-17 crew co-op.** A host now opens two extra signalling rooms after the three crew
rooms (`crewCode` slots 3 and 4, `SPEC_SLOTS`). It does this in the background and on a best-effort
basis: if a room clashes, that game simply can't be watched. A player can watch a crew in three ways:
- type the code and press **Watch** (next to Join in the co-op menu);
- press **Watch** on a row of the public game list.

A spectator is a guest without a gun:
- It gets the same lobby, start, snapshots, kills, hits, weather and end messages as the gunners.
- It never sends gun input.
- It is left out of the roster, the seats, the `remoteStations`, the public listing's crew count, the
  debrief split (it gets the crew result and earns no merit, medals or service record) and host
  migration (it is never the heir).
- It can join mid-round: the host sends the `start` on its hello.
- If its link drops, it reconnects to the spectator rooms. If the host leaves, it gets "the broadcast
  has ended".
- The host lobby shows "Spectators watching: n".

**What a spectator sees** (`game/Spectator.ts`, overlay `ui/SpectatorHud.ts`):
- **Any gun position (keys 1–5).** The local gunner controller sits at the watched station. Each frame
  its target aim is set from that gunner's streamed aim. The view is the real first-person one
  (interior, sight, recoil spring) and turns with the gunner. Aim magnetism and player input are off
  while watching, and there is no pointer lock, so the bar can be clicked. AI-crewed guns can be
  watched too.
- **Cinematic camera (C).** Calm shots of our B-17 (chase, wing, belly, head-on) with a slow drift
  during each shot. Whenever a fighter is within 1.8 km it cuts to an over-the-shoulder shot past the
  ship at that fighter.
  - It never shows two fight shots back to back and never cuts before 2.5 s.
  - It uses the film look's `cinema` shot and reveals the hull parts the gunner view hides.
  - The 2D canvas (reticle, markers) is hidden in this view.
- **The bar:** one row with the five positions (with who is on each one, or "AI gunner") and the
  cinematic camera, plus "Stop watching". A firing dot shows which guns are shooting. ← → switch
  views (mirrored for RTL). A SPECTATING tag and a delay tag sit at the top. The gunner's own panels
  (ammo, heat, abilities, Leave co-op, Ping) are hidden. The crew score, kill feed and subtitles stay.

**Crew aims in every snapshot.** The host adds `ca` (yaw/pitch for each of the 5 stations) and `cf`
(a mask of the guns that are firing).
- Sources: the host's own gun comes from its controller; the other guns from the ship's gun mounts
  (AI and remote gunners).
- Side benefit for normal crews: every guest's ship now swings its crewmates' guns, not only the
  host's. It skips its own station and allocates nothing (cached vectors).
- Cost: about 80 bytes per snapshot, inside the existing 1400-byte budget, which trims tracers first.

**Broadcast delay** (`SpectatorRules.DelayLine`). Settings → Advanced → **Spectator delay**: Off / 5 /
15 / 30 / 60 s, also on the co-op menu.
- What is held back: snapshots and the `start` / `k` / `h` / `end` / `debrief` / `wx` / `mark`
  events, in one first-in-first-out line, in arrival order. They are released `delay` seconds later
  (wall clock).
- What stays live: lobby and seat traffic, so the picture stays consistent: the mission even starts
  late.
- While a held `start` waits, the spectator's lobby counts down ("your delayed picture begins in n s").
- Limits: the line is capped at 2400 messages, and a gunner never delays anything.

**Streamer mode** (Settings → Advanced, `ui/Streamer.ts`):
- **No personal info on screen.**
  - The join code in the lobby and the cloud-save transfer code are masked. A **Show** button reveals
    them for 5 s.
  - Callsigns in the crew list, the spectator bar and the host's partner kill-feed line become
    "You" / "Gunner n".
  - Your own row in the leaderboards and the career card name read "You".
  - The callsign and leaderboard name inputs are blurred until focused.
  - The game browser drops "Your region".
  - A failed invite copy no longer prints the link.
- **Big readable HUD:** the HUD text panels, kill feed, subtitles, tips and the spectator bar are shown
  at 1.3×.
- **No FPS counter.**

Arabic for every new string is in the new `src/i18n/ar/spectator.ts`, including the Field Manual line
about Watch, delay and streamer mode.

## Not done / caveats
- **No live-network playtest across machines.** The test was three tabs on one Mac.
- **The links dropped at mission start in the test.** Under SwiftShader the first mission build stalls
  the host past the 10 s link timeout, even after a warm-up mission. Both the gunner and the
  spectator rejoined by themselves (existing Rejoin path, spectator rooms included). The rejoined
  gunner lands on a free seat, so the check moves it back to the tail. This happened before this goal
  too and isn't caused by it, but it would be worth a look on slow devices.
- **One spectator line per game, two seats.** A third watcher gets "No spectator seat free".
- **The delay holds the picture only.** Kill-feed lines the host itself writes are local to the host.
  A spectator's audio (radio, music) is driven by the same delayed events.
- **The spectator's first-person view reuses the local gunner controller,** so the view snaps to the
  station with the usual 0.9 s crawl fade on a switch. The watched gun's muzzle flash and recoil are
  not replayed: the host's sampled tracers show the fire.
- **No P-51 (pilot mode) spectating.** The spec covers the crew.
- **No quality-gate comparison with the capture rig.** This goal is UI and networking with no
  rendering change, so the capture rig was not run. The new cinematic shots reuse the existing film
  look and shot presets.
- **The `PW_SHELL` override in the check script** is only there because the npx Playwright on this
  machine expects a newer browser build than the one already downloaded. No browser was installed.

## Review round 2 (fixes after the rejection)
1. **The Arabic shot was in English.** Cause: the check's `import('/src/i18n/index.ts')` loaded a
   second copy of the i18n module in the dev server, so `setLang('ar')` set `<html dir/lang>` but not
   the game's live language. Fix: a dev-only `sws.setLang` hook in `src/main.ts` (the game's own
   instance), used by `tools/spectator_check.mjs`. The bar already redraws on a language change (its
   redraw signature includes `<html lang>`).
2. **Gun-position names.** "Left Waist", "Right Waist", "Top Turret", "Ball Turret", "Tail Gun" were
   already in `src/i18n/ar/tour.ts`, `career.ts` and `loadout.ts` (Arabic: الجانب الأيسر، الجانب الأيمن،
   البرج العلوي، البرج الكروي، مدفع الذيل). The check now asserts each one is on the Arabic bar, and
   that no English word is left on the bar, the score line or the round line.
3. **Arabic proof.** `spec-ar.jpg`, `spec-phone.jpg` and the new `lobby-spectator-ar.jpg` are all
   Arabic. The spectator's lobby now also shows "Spectators watching: n" (`CoopScreen.watchLobby`).
   "AI gunner" is now "الرامي الآلي" (as in the lobby): "رامٍ" broke up in the small mono font.
4. **Streamer-mode overlap.** `SpectatorHud.clearCorners()` (runs with the 5 Hz bar refresh) drops the
   SPECTATING/delay tags below the HUD's top-corner text whenever the two would meet. On phones
   (≤ 640 px) streamer mode zooms the top HUD text 1.15× instead of 1.3×, and while spectating the
   top-left block may use up to 62 vw (the gunner's bottom panels are hidden then), so the round line
   is no longer cut off at 390 px. Measured gaps (`verification.json` → `gap`): at 1280×720 in English and Arabic the
   tag and the score block don't overlap horizontally ("apart"); at 390 px wide the tag is 8 px below
   the block in both languages.

5. **Check script robustness.** After the start-time link drop the gunner can rejoin under a new id,
   so the streamer assertion now expects "Gunner <id + 1>" from the gunner's real id and waits for the
   spectator's bar to show it on the tail, instead of a hard-coded "Gunner 2".
