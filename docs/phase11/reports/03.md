# Phase 11 · 03 — Final review: scope reduced to cloud penetration

Final follow-up to rejected head `982d01b`, on `phase11/03-film-clouds`.

**The general film-grade cloud replacement is withdrawn.** The final review explicitly allowed reverting regressions. A lower, connected version still did not consistently beat LIVE, so fair-weather and overcast skies now use the production density, lighting, horizon march, shadows and god rays. The retained change is the visibly better dense-cumulus fly-through, with cloud condensation. This is not an 8/10 or MSFS-parity claim.

The branch lacks `docs/phase11/reference-pack.md`; the main checkout's copy was read, alongside the task, architecture, Phase 10 references and scorecard. No third-party imagery or assets were added.

## Implementation and hooks

- `src/render/Clouds.ts:106,329,445`: keeps the production `deckDensity`/`marchDeck` path. A scalar uniform selects the retained `towerDensity`/`marchTower` only for dense convection. Coverage blends from 0.65 to 0.85; stratus blends it out from 0.6 to 0.9. Density, layer height, extinction and mist blend through weather fronts. Upper cloud shapes retain the production field. Both paths are compiled during normal prewarming; weather changes do not create material variants.
- `Clouds.ts:951,1103`: `CloudRenderer.lowTop` and uniform synchronization keep receiver shadows and the density probe on the actual layer. Fair/overcast top: 5.9 km; fully convective top: 8.5 km.
- `src/core/Engine.ts`: restores production High **0.36 / 40 steps** and Ultra **0.45 / 52 steps**. Low remains **0.18 / 20 steps**. Dense convection alone uses a reduced uniform march budget (`Clouds.ts:1118`): **28 High / 36 Ultra**, blending through the weather front. This retains visible penetration depth without reducing fair-weather resolution.
- `src/render/LensScatter.ts`: fully restored to production. The added cloud aerial shaft integration and height-sliced shadow texture are removed.
- Retained from earlier commits: `src/render/noise.ts` curl channels; `src/game/GlassFx.ts` cloud film/beads and evaporation; deterministic probe settling in `src/dev/VisualRigPage.ts`; matched production camera/aircraft/gun harness.
- `Clouds.ts:1178`, `tools/cloud_live_compare.mjs`, `tools/cloud_detail_check.mjs`: fixed capture jitter phase and probe/camera-cut ordering on both sides; use the same 24 settling frames. Production shaders are never replaced. `tools/visual_rig.mjs` now preserves failed repeat images/metadata for diagnosis while keeping the manifest incomplete.
- `tools/cloud_runtime_check.mjs`: asserts that tall clouds are confined to dense convection, while retaining penetration, condensation, cut/rebase, finite-history, Low and shader-count checks.

No new dependencies, strings, render targets or per-frame allocations. No main push or deployment.
