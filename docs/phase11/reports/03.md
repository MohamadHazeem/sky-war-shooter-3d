# Phase 11 · 03 — Film clouds

Implemented on `phase11/03-film-clouds`. Cloud heads now retain more shape at formation distances, with curling edge erosion, deeper shaded bodies and narrower sunward highlights. [Live / isolated baseline / final comparison](../shots/03/comparison.jpg).

## Changes and hooks

- `src/render/noise.ts:107`: deterministic periodic curl packed into the existing detail volume's GBA channels. R retains the original erosion data, including for Low. Adds approximately 110 KiB with mipmaps; generated at startup, no downloaded assets.
- `src/render/Clouds.ts:127`: wider maturity-driven height variation, asymmetric shoulders and two erosion scales. The finer erosion is distorted by the packed curl; shadow/probe marches share the broad shape.
- `Clouds.ts:178`: three midpoint light samples reach farther through neighbouring cloud bodies, with filtered distant samples. Multiple-scattering octaves become progressively less directional; sky fill falls inside dense cloud, and the silver-lining lobe narrows.
- `Clouds.ts:271`: continuous quadratic sample spacing concentrates work on nearer heads and tightens further around the eye. Body filtering follows the ray interval; erosion follows projected pixel size. Existing checkerboard reprojection, wind compensation, clipping and cut/rebase invalidation remain active.
- No hooks added to Game, World or Engine. Existing prewarming covers the same materials. Cloud shadows, gap-driven screen-space shafts, in-cloud fog and glass condensation consume the revised density/transmittance. No new passes, runtime material variants, CPU frame allocations, dependencies or player-visible strings.

## Remaining limits

The formation and sunset shots clearly improve over live main, but this is not MSFS parity. Near cloud shoulders remain soft at High's existing .36 cloud scale; broad density lobes and distant contrails are still conspicuous. God rays remain the existing screen-space approximation, not a new volumetric air-scattering solution. Fog/droplets were retained and verified, not rebuilt. No WebGPU verification, deployment, new art, or changes to other branches.

Reproduce with `PLAYWRIGHT_EXECUTABLE` pointing to an already-installed **headless shell**, `CLOUD_URL=http://127.0.0.1:5323`, and the existing `tools/heavy.sh` wrapper: `tools/visual_rig.mjs`, `tools/cloud_live_compare.mjs`, `tools/cloud_detail_check.mjs`, `tools/cloud_perf_ab.mjs`, `tools/cloud_verify.mjs`, and `tools/cloud_runtime_check.mjs` (set `CLOUD_OUTPUT=docs/phase11/shots/03/runtime`).
