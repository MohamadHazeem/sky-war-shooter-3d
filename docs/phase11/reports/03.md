# Phase 11 · 03 — Cloud quality-review fixes

Follow-up to rejected head `b34aee6`, on `phase11/03-film-clouds`.

## Changes

- `src/render/Clouds.ts:134`: coverage floor and smooth support gate remove weak, detached edge fragments. Bounded erosion and a steeper density gradient keep the surviving billows defined. Slight altitude-dependent curvature prevents straight coverage walls. Dense-weather interpolation preserves the accepted fly-through structure.
- `Clouds.ts:374,432`: cooler backlit bodies, a neutral bright rim and revised view-transmittance gating separate silver edges from opaque cloud. Opaque march termination no longer leaks the HDR solar disk.
- `Clouds.ts:583`, `src/render/LensScatter.ts:85`: reduce the broad aerial veil and concentrate shafts in paths containing both a cloud opening and a caster. The tower-gap view now has distinct downward beams rather than uniform tan haze.
- `src/core/Engine.ts:52`: High cloud scale increases **0.30 → 0.33**, retaining 48 steps and temporal reconstruction. Ultra uses **0.42 / 52 steps** (previously 0.45); Low remains **0.18 / 20 steps**. These budgets preserve the complete lighting march. No new render targets, runtime shader variants, per-frame allocations, dependencies or player strings.
- `tools/cloud_live_compare.mjs`: restore and assert all 18 aircraft roots and gun transforms before applying the reference camera. Production startup had displaced roots by 5.7–9.7 m, enough to move the turret out of frame. The comparison board now rejects mismatched cameras, weather or unverified aircraft/gun poses.

The existing tower envelope, cloud shadows, temporal history and glass-condensation implementation remain.
