# Phase 11 goal 23 — Escort fighters

Implemented P-47D Thunderbolt and standard-wing Spitfire Mk IX escorts using the official
FlightGear shapes (Syd Adams / Detlef Faber), with new PBR atlases, Allied markings, three
LODs, KTX2 and embedded WebP fallback, named structural parts, moving controls and propellers.

## Integration

- `src/world/EscortTypes.ts`: deterministic mixed roster, aircraft-specific flight response,
  prop radii, gun mounts and labels.
- `src/world/Models.ts` / `HeroLook.ts`: loaded before menu escorts spawn; reuse existing
  screen-size LODs, Low's far-only rendering and background KTX2 upgrade.
- `src/world/World.ts`: optional escort kind, shared allied construction, support DPS normalised
  to the previous P-51 escort, type-specific hit-zone locations, all variants prewarmed.
- One spawn hook each in `Game.ts` (menu bomber formation), `MissionFlow.ts` (escort missions),
  `Director.ts` (gunner reinforcement arrivals). Counts/timing unchanged. Player aircraft,
  named Mustang ability/set-piece and co-op player wingmen remain P-51s.
- `CoopSession.ts`: escort identity survives snapshots; `Recorder`/`Theatre` already store and
  instantiate model kinds. `destruction/Parts.ts`: fitted structural splits and aircraft masses.
- `src/i18n/ar/escorts.ts` registered in `phrases.ts`: Arabic aircraft labels. No new radio lines.

Hook lines: `World.ts:319,588`, `Game.ts:318`, `MissionFlow.ts:127`,
`Director.ts:290`, `CoopSession.ts:1142`, `Models.ts:30,44`, `HeroLook.ts:20`,
`phrases.ts:51`.

## Assets and reproducibility

`tools/hero/escorts/README.md` documents source/license links, pinned archive SHA-256 hashes,
conversion inputs, rebuild and capture commands. Derived assets and source conversions are
checked in. `tools/convert_models/configs/{p47d,spitfire9}.json` removes alternate wings,
duplicate surfaces, external stores and P-47 extended gear. The shared hero baker's escort
spec and Allied painter live in `tools/hero/luftwaffe/`.

The task did not specify a port. Port 5323 belonged to the clouds task, so this task used
**5423**, with the installed Playwright **headless shell**. All bakes/captures used `heavy.sh`,
and asset builds used `cached.sh`. No dependencies installed, desktop browser launched,
or deployment performed.

## Scope

These are AI escort exteriors, not selectable player aircraft or parked-aircraft assets.
The liveries are representative Allied schemes; no claim of matching a specific serial or
individual historical airframe. Spitfire support weapons use the existing arcade ballistic
profile, with correctly located wing muzzles and the existing total escort firepower budget.
