# Phase 11 · 32 — More languages (French, German, Spanish): report

Branch `phase11/32-more-languages`. The game now plays fully in **English, Français, Deutsch, Español and
العربية**. Voices stay English; only the shown text changes, the same way as Arabic.

## What changed
- **Same table system as Arabic.** Every Arabic phrase table `src/i18n/ar/<name>.ts` has a French, German and
  Spanish twin, `src/i18n/{fr,de,es}/<name>.ts`: 59 tables × 3 = 177 files. Each has the same English keys
  (4,579 phrases) and the same 317 runtime regex patterns, with replacements written per language (plurals,
  articles, the generated raid, weekly and campaign briefings). Interface keys (`en.ts`) are in
  `src/i18n/ui/{fr,de,es}.ts`. Precedence is the Arabic merge order from `phrases.ts`, and new files are
  auto-discovered (`src/i18n/pack.ts`).
- **Lazy loading.** Arabic stays in the main bundle. Each new language is its own chunk
  (`src/i18n/packs/{fr,de,es}.ts`, about 415 KB raw each), so English and Arabic players don't download
  them. Boot waits for the stored language before the first menu (`main.ts`:
  `await Promise.all([essentials, langReady()])`). `setLang()` now returns a promise; screens rebuild when
  the pack has arrived.
- **`src/i18n/index.ts`:**
  - `Lang` is `'en' | 'ar' | 'fr' | 'de' | 'es'`, with a `LANGS` list (each name in its own language).
  - The browser language picks the start language when nothing is stored.
  - Lookups are per language.
  - Upper-cased display text (`LEFT WAIST`) is upper-cased in the translation too, with placeholders and
    markup left alone.
  - New helpers: `isTranslated()`, `loadLang()`, `langReady()`, `txIn(lang, text)`, and
    `hasPhrase(text, lang = 'ar')`.
  - `num()` uses each language's thousands separator.
- **Language picker:**
  - Settings → Language lists all five languages.
  - The title screen has a small globe picker next to Hangar / Settings (`UI.title`, `simpleMenu.css`), so a
    player who doesn't read English can find it.
  - Switching from either picker rebuilds the screen in place (`SimpleMenu` `relang → startMenu`).
- **`isAr()` checks that really meant "translated"** now use `isTranslated()`:
  - crew-room subtitles and their reading time (`CrewRoomScene.ts`, two places)
  - crew-story letters (`CrewStoriesPanel.ts`)
  - the FPS readout (`FpsCounter.ts`)

  The RTL-only ones (mirroring, Arabic list separators, Arabic fonts) stay Arabic-only.
- **Docs:**
  - `AGENTS.md`: new goals should add `fr/de/es` twins of their Arabic table.
  - `README.md`: the language line now lists all five.

## Tests
- **New `tests/i18nLocales.test.ts`**, run for each of fr / de / es:
  - Every `en.ts` key is translated, keeping its placeholders and markup.
  - Every table file has an Arabic twin and only that twin's keys (catches typos), with identical pattern
    regexes in the same order.
  - Values keep `{placeholders}`, HTML tags and "Sky Queen", and contain no Arabic.
  - Gaps against the Arabic tables stay under 1% (currently 0 of 4,579 in each language). The 1% margin lets
    goals merged later add a few Arabic lines first.
  - Full coverage of every mission text, upgrade, station, crew member, recorded radio line, skill, mode and
    news card.
  - Runtime strings (side raids over 30 campaigns, custom battles, 53 weekly challenges) translate wherever
    Arabic does, and no pattern leaves a `$1` unfilled.
  - Pack switching, the stored choice and upper-casing.
  - Gap list for maintainers: `I18N_GAPS=1 npx vitest run tests/i18nLocales.test.ts`.
- **`tests/menuRouting.test.ts`** now expects the title's new `relang` handler.
- **Full local check:** `tsc --noEmit`, `vite build` and the whole vitest suite (115 files) pass. The only
  local failure was that `relang` handler (fixed). The suite was run with `--fsModuleCache=false`: the
  module cache kept a stale `import.meta.glob` file list while the new table files were being written. A
  fresh CI checkout does not have that cache.

## Translation choices (for a native-speaker pass later)
- **Kept as in English:**
  - unit names and US medal names (401st Bomb Squadron, Purple Heart, DFC…)
  - Luftwaffe ace ranks and names, and the German Luftkreuzer names
  - operation code names, nose-art names and crew call-signs (Skipper, Tex)
  - aircraft designations
- **Forms of address:** French uses *vous*, German *du*, Spanish *tú*.
- **Grammar:** a few patterns build sentences from generated parts (raid targets, places "over {place}",
  letter senders). The translators gave those parts articles or cases so the sentence reads right. In German
  some of these words would read slightly wrong if shown on their own.
- **Done by machine:** the translations were written by model agents, one group of tables each, and checked
  by the tests above. No native speaker has reviewed them yet.
