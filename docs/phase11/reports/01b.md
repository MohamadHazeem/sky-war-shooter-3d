# Phase 11 · 01b — Sketchfab fighters and original exterior crew

Implemented on `phase11/01b-sketchfab-fighters`. No deployment or main-branch push.

- **Bf 109 / Fw 190:** supplied GRIP420 / Saman Salili CC BY 4.0 airframes, normalized to 9.924 / 10.5 m span and the game axes. Original 74/75/76 paint, Reich bands, markings, softer sprayed mottling, wear, cockpit/pilot/propellers, G-6 cowl blisters, Fw 190 hood seals, working controls, and three LODs. Removed deployed source gear, boarding step, and costly bolt/spring geometry.
- **Destruction:** all seven contract names own actual geometry, including explicit `part_core` and `part_nose`; joint/fuel markers are present. The inherited fuselage aliases remain for the hero LOD runtime.
- **Crew:** replaced inherited figures/materials/textures in both B-17 exteriors, P-51, Do 335, He 111, and eight archived converted aircraft. The replacement is a seated, forward-looking variant of our own `public/models/crew.glb`, about 3,500 triangles. Other Luftwaffe hero pilots were already original project geometry. Rebuild hooks prevent inherited figures returning.
- **Credits:** both authors, CC BY links and modifications in `public/models/CREDITS.md`, plus English/Arabic in-game credits. Removed the inherited pilot credits.
