# Phase 11 · 20 — Replay and photo mode 2.0: report

Branch: `phase11/20-replay-photo-2` · Lane: Cloud (Claude, no GPU / Blender / voice tools)

## Starting point
The Phase 5 replay theatre (`Theatre.ts` / `TheatreScreen.ts` / `Recorder.ts`) already had a 90 s
recording, a timeline with best-moment ticks, Player / Orbit / Free / Director cameras, 0.25–2× speeds,
photo settings (FOV, DOF, focus, exposure, 1–3× PNG screenshots) and saved moments. This goal adds
what was missing from the spec and keeps the existing flow and layout.

## What changed
- **Chase camera** (new 5th mode, key `5`, also in the gamepad / phone mode cycle): sits behind and
  above the selected aircraft along its flight path. The offset is smoothed relative to the subject,
  so a fast fighter can't outrun the camera. Picking an aircraft in the list while in Chase switches
  the subject and stays in Chase. The DOF focus follows the subject.
- **Slow motion**: a new 0.1× speed, plus a "Slow motion on moments" switch. When it is on, playback
  eases down to 0.2× around every timeline moment (0.8 s before to 1.4 s after, with smooth 0.6 s
  ramps) and never runs faster than the chosen speed. It doesn't allocate per frame, and it is off
  during the Combat film, which has its own pacing.
- **Film looks**: a "Film look" picker in the Photo panel: As in Settings / Clean / Film /
  Kodachrome / Newsreel B&W. It is the theatre's own choice: Settings is restored on exit. The look
  only changes uniforms, so there is no shader recompile. On Low (economy) the film pass stays off,
  as it already does in play.
- **Share card** (one click): renders the current view and composes a 1200×675 card with a cover
  crop, a khaki frame, the moment label, the mission title, "N kills in this replay · <film look>",
  the game name and the URL. It is shared through Web Share (files) where supported; otherwise it is
  downloaded and the text and link are copied to the clipboard. Arabic cards are drawn RTL.
- **WebM clips** (one click, "Record clip"): picks the best moment (weighted marks: boss > ace >
  multi-kill > close call > kill; later marks of the same fight extend the clip up to 14 s; with no
  marks it uses the playhead), seeks there, plays it with the current camera, speed, slow motion and
  look, and records the canvas with `captureStream(30)` + `MediaRecorder` (VP9, then VP8, then plain
  WebM; 8 Mbit/s). It stops at the end of the window, on pause, on a second click ("Stop recording"),
  on exit, or after 40 s of real time. Then it downloads the `.webm`. A blinking red REC tag shows in
  the top bar while recording. Browsers without MediaRecorder WebM get a clear status message.
- Arabic for every new string in a new table `src/i18n/ar/replayStudio.ts`, prepended to `TABLES`.
  The keyboard help line changed to "1–5 camera" in both languages.
