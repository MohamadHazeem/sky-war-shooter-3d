# HDR sky look references

Viewed 2026-10-15; no HDR texture or reference photograph is shipped in the game.

- [Kloofendal 48d Partly Cloudy (Pure Sky)](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky), Greg Zaal / sky edits Jarod Guest, Poly Haven, **CC0**. Neutral sunlit cloud whites against cool blue fill; broad cloud shapes reflected in rough metal.
- [Kiara 1 Dawn](https://polyhaven.com/a/kiara_1_dawn), Greg Zaal, Poly Haven, **CC0**. Violet shade with peach horizon highlights, used to restrain yellow sunset grading.

The reference previews were downloaded only to temporary files for visual inspection. `FilmLUT.ts` uses hand-tuned coefficients; `Sky.ts` captures the game's procedural atmosphere with low-frequency cloud variation. No new runtime download or asset licence obligation.
