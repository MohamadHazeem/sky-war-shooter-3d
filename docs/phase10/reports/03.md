# Phase 10 · Goal 03 — Clouds & sky

Implemented on `phase10/03-clouds`; WebGL2 / reversed-Z, Apple M5 Pro, Chrome 155 (ANGLE Metal). No dependencies, downloaded assets, player-facing strings, voice lines, push, or deployment.

## Changes

- Weather-map G now controls cumulus maturity and tower profiles; overcast produces stratus, storms increase convection, and weather fronts blend these values. Beer–Powder, three scattering octaves, dual-lobe phase and silver linings build on the existing renderer.
- Fixed horizontal bands caused by implicit weather-map derivatives inside divergent raymarch loops. Cirrus uses a spherical shell, reduced directional stretch and footprint filtering instead of the old flat-plane projection.
- Kept checkerboard temporal reprojection, wind compensation and neighborhood clipping. Added near-eye quadratic sample spacing, skipped fully occluded second layers, rejected stale density-probe results after cuts, and kept shadow coordinates stable across rebasing.
- Two-channel cloud shadow map: separate low/high transmittance projected at each layer's altitude. Terrain receives both; aircraft skins sample shadows spatially through the existing clone-safe material hook, with independent lighting across the formation.
- A startup-baked spherical Rayleigh/Mie optical-depth LUT supplies altitude-dependent sky and aerial extinction. Existing mission palettes remain, including night and storms. This is a compact two-species approximation inspired by [Bruneton's transmittance approach](https://ebruneton.github.io/precomputed_atmospheric_scattering/), not the full precomputed multiple-scattering model. Cloud design follows the weather/type/profile concepts described in [Guerrilla's Nubis presentation](https://www.guerrilla-games.com/read/nubis-realtime-volumetric-cloudscapes-in-a-nutshell).
- The GPU camera-density probe drives light loss and existing canopy/turret droplets. Contrails use cylindrical optical-depth self-shadowing and sunset colour, and local/distant ribbons fade behind clouds. Existing cloud-transmittance-driven god rays remain active.
- Low retains the original 36-step, 0.33-scale, non-temporal density/march path. New atmospheric lookup, spatial shadows, condensation and cloud-buffer ribbon occlusion are disabled on Low.

## Self-score and limits

Pillar 3: **6/10**, up from the phase plan's 2/10. Cloud fields now have stronger vertical relief without grazing-angle bands, layer-specific shadows and a convincing opaque interior. This is not yet MSFS/Nubis visual parity: the fixed captures still show soft distant detail and the large formation's ribbon trails remain conspicuous.

Secondary whole-pillar estimates: lighting **3/10**, ground **2/10**, effects **3/10**, interior **2/10**, performance **7/10**; this task only changes their cloud-related contributions.

The atmosphere is a small optical-depth LUT plus analytical/artist-directed scattering; cirrus is a thin shell, not a third raymarched volume. Shadow maps cover a finite 52 km area and fade at their edges; in-layer spatial shadows approximate partial optical depth. Transparent cloud occlusion uses representative depth, not a full deep-opacity buffer; other transparent effects still follow the existing pipeline. God rays are the existing screen-space approximation. Renderer 2.0/WebGPU was not merged into this checkout, so native WebGPU was not verified; new LUTs/shared uniform modules add no dependency on a particular post stack, while the existing WebGL2 path remains supported.

Own port-5303 dev server stopped. No push or deployment. Full-resolution PNGs were kept outside the checkout at `/tmp/codex-03-clouds-fullres`; committed evidence is the small JPEGs and JSON/Markdown records.
