# Phase 10 reference board

Use these public pages as visual references, alongside [the fixed baseline](shots/baseline/contact-sheet.jpg) and [scorecard](scorecard.md). Links only: no third-party frames, stills, textures or models are copied into the game. Public viewing does not grant asset reuse rights. Film grade and dramatic framing are artistic targets; archive photography anchors proportions and equipment.

The learning points below are our art-direction checklist, not claims that a reference implements a particular rendering technique. Sources were located on 2026-10-14. YouTube playback was unavailable to the text browser; the 00:54–00:58 waist sequence is the reference already specified in this repository's README. The NARA presentation is an 11 MB PDF; search its captions for the named photograph.

## Scoring discipline

Score each pillar once after inspecting all its relevant shots: 0 absent/broken, 1–2 current rough baseline, 3–4 readable but visibly simplified, 5–6 coherent game art, 7–8 convincing close inspection, 9–10 the film/simulator reference bar. Scores remain human judgments, with a short reason and a before/after pair in each goal report. The owner's initial estimates in [PHASE10](../PHASE10.md) are context, not automatically assigned scores.

Keep the camera, seed, weather and fixture version fixed for before/after work. Changes to shot composition require a fixture-version bump and recapturing both sides. Objective luma, edge and colour metrics help identify regressions such as clipping or lost detail; none is a quality score to maximize.
