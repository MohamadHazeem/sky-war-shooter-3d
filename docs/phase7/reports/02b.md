# Phase 7 / 02b — Sea Strike visual pass

Rebuilt the procedural fleet and coast on `phase7/02-naval-strike`.

- Shaped, flared hulls with sheer, rounded sterns, boot topping and antifouling; contrasting decks, bridge windows, capped funnels, masts/yards, boats, rails, anchors and fittings. Corrected lengths: battleship **250 × 36 m**, destroyer **120 m**, merchant **130 m**, U-boat **67 m**, E-boat **33 m**. The player's P-51 retains its native scale.
- Battleship: four elevated/traversing twin main turrets in superfiring pairs, six secondary twins, eight combat flak mounts, stepped tower bridge/director, single funnel, cranes and transverse catapult. Destroyer: two funnels, four single mounts and torpedo tubes. Type VII: saddle tanks, rounded tower, railed platform, periscopes and deck gun. Merchant: cargo hatches and derricks; E-boat: fore/aft guns.
- Pooled muzzle flashes, expanding gun/exhaust smoke, decorative flak tracer streams, salvo shell-fall columns and bullet/skip-bomb splashes. Extra auxiliary guns/tracers are visual: damage, firing cadence, waves and the battleship disarm gate retain their rules. Hit volumes follow the corrected dimensions/mount positions; explicit heavy-ship classification preserves destroyer armour and 32-second sinking.
- Noisy, textured beach/cliff/scrub terrain with strata, rocks, animated surf, block mole/lighthouse/buildings, textured casemates with slits/netting, sandbag AA pits, rotating radar and four-corner flak tower. Foundations reach the retained terrain collision shelves.

## Files / hooks

- `src/world/SeaModels.ts`: cached merged hull/detail sections, fittings, terrain, procedural texture and foam ribbon.
- `src/world/SeaEffects.ts`: fixed 256-slot effect pool, existing tracer renderer, reusable matrices/typed arrays; no per-frame object allocation.
- `src/world/SeaWorld.ts:86`, `:162`, `:176`, `:210`: model assembly, gun effects, LOD/exhaust/radar update and prewarming. Fine detail disappears on Low or beyond 1.8 km; Low reduces exhaust/spray. New materials use the existing `World.prewarm` hook. Foam opacity and terrain radiance are clamped before HDR output.
- `src/world/SeaCombat.ts:5`, `:22`, `:43`: dimensions, preserved heavy-ship rules, mount alignment.
- `src/game/SeaOps.ts:118`, `:165`, `:203`, `:261`, `:268`, `:279`: viewer distance, splashes, elevation, firing/salvo effects.
- `src/dev/seaQa.ts:32`: refresh detail for the inspection camera. `tests/sea.test.ts:143`: proportions, finite geometry, turret layout, effect capacity/expiry, LOD and radar checks.

## Verification

`npm run check` passed: TypeScript, production build, **563 tests / 52 files**. Existing weapon, sinking, diving, floating-origin and Arabic tests pass. No new player-visible strings or radio lines.

Chrome verification used this worktree's Vite server on **5272**, `sws.step`, `sws.sea`, `sws.vqa` and a temporary local capture harness. Initial native-browser inspection was followed by isolated headless Chrome when the native window became unavailable. Final captures cover all weather moods, Low, sinking/diving, gun elevation, flashes/smoke/tracers, splashes and shore detail. These are scripted visual checks, not a full human balance playthrough.

All **27 captures** passed HDR checks: zero NaN/Inf, negative or over-threshold pixels; no page/console errors. Gun elevation and Low detail checks passed.
