# Phase 7 goal 04 — Co-op escort

Implemented on `phase7/04-coop-escort`. No push, deployment, dependency installation, or live leaderboard submission.

## Changes

- The existing room-code lobby now offers B-17 crew or P-51 escort. The host chooses Survival, a campaign escort sortie, or saved Custom Battle escort settings; guests see the selection. Pilots are Blue One / Blue Two. New copy is in `src/i18n/ar/coop.ts`; no new recorded radio lines or audio files.
- `src/game/CoopPilot.ts` owns local-flight/remote-fighter motion, stale-input release, authoritative damage/fire/ammunition events, bail-out/spectating, round respawns and AI replacement after disconnect. Enemy AI can attack and dogfight either Mustang. Six real host-side guns resolve guest hits and kills; guest bullets are visual only. Existing formation radio is retained, with a separation reminder and named distance markers.
- `src/net/CoopPilot.ts` validates quantized 30 Hz input and life epochs, and encodes 28-byte aircraft records (32-bit IDs, float positions, quantized quaternion/health, damage flags) inside the existing JSON transport. Snapshots run at 20 Hz with the existing 100 ms interpolation buffer. Pilot tracer samples are capped at four and trimmed to a 1,400-character snapshot target; aircraft are retained. `src/net/Coop.ts` counts transmitted/received application bytes.
- `CoopSession.ts` reuses the world proxies, separate personal ledgers, shared HUD score, reliable kills and both debriefs. Only the host gets the combined `Blue One + Blue Two` submission form for `coop-pilot`; Custom Battle remains unranked. `Leaderboard.ts` preserves both names even with a squadron profile. `LeaderboardPanel.ts` recognizes pilot crews. The local Firestore regex/name limit preserves every existing mode, including `survival-sea` and `survival-aa`.

## Boundaries / reviewer activation

- Sea Strike, Hold the Field, Train Busting, raid/night operations remain solo. Escort co-op disables battle-group bosses, special/mid-round events and hangar pauses; campaign sorties do not advance the solo strategic campaign. Custom Battle uses the host's saved escort settings with those exclusions. Battle-group/ground objects are outside the aircraft snapshot protocol.
- Escort Mustangs currently have no player rockets/bombs or gear/flap controls; no new weapons were invented. Gun damage/loadout is host-authoritative. Damage, kills, revival and debrief use the reliable channel; continuous gun trigger uses flight input.
- Browser verification exercised STUN with host/server-reflexive candidates. Existing TURN configuration/fallback and its unit tests remain intact; actual relay traversal was not tested because no TURN credentials were configured.
- Firestore changes are **local only**. The reviewer must merge/deploy the rules before `coop-pilot` submissions are accepted. No secrets or voice-render output were touched. The dev server was stopped after verification.
