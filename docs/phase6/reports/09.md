# Phase 6 · 09 — Squadron leaderboards

Implemented on `phase6/09-squadron-boards`. The original implementation report below records the earlier deployment restriction; the **Live fix** section supersedes that status.

- Create/join/leave with cryptographic six-character codes, atomic membership/count changes, one squadron per identity, and a 64-member cap. Names use 36 approved word pairs; callsigns are fixed once. The `sws3d.squadron` profile mirror is included by the existing cloud-save mechanism. Imported caches never grant membership to another anonymous identity; that identity must register/join.
- Every leaderboard gets Global/Squadron tabs and Refresh. The Squadron title screen shows members, personal bests for selectable modes/campaign missions, separate weekly gunner/pilot standings, and recent join/Experte activity. Departed members are excluded from standings. Weekly keys roll over using the existing UTC weekly challenge logic.
- Public score submissions carry an opaque 32-character squadron ID, **never the invitation code**. Private bests are linked to validated global submissions in the same transaction. Global scores remain public; the screen explains this. All new interface/error/name strings have Arabic; mobile RTL was checked.
- Activity keeps the latest event per member, displays the latest 20, and rate-limits Experte updates. Refresh is explicit rather than a background subscription. No frame-loop hooks or new render materials/dependencies.
