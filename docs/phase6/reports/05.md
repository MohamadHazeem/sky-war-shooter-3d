## Changes

Optional Norden seat offered 30 seconds before release: remappable N, gamepad Y, or touch. Magnified, stabilised nose view includes the existing city, drifting clouds and flak, with course/rate indexes. Arrows/stick steer the autopilot and adjust tracking rate; Space/RT releases; B/LT holds for a cloud gap. Release occurs at the sighting angle, with a 12-second late limit. Ignoring/leaving the seat retains automatic bombing.

A deterministic pattern combines release position/heading, wind and flak jolts. The same coordinates drive carpet impacts, percentage within 304.8 m (1,000 ft), and strike-photo marks. Up to 1,000 bombing score feeds the existing debrief merit calculation. The photo uses a real rendered target frame after impact and pulls back for wide misses. Career adds backward-compatible `bestBombing`; “Pickle Barrel” requires strictly >80%. All new text has Arabic. Emden gets release at 85 s / offer at 55 s; Ludwigshafen retains 112 s / 82 s.

No new dependencies, materials or shader variants. Frame-path vectors are reused; patterns/photos allocate once per run.
